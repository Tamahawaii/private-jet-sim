# JETSTREAM — AI Personas (The Killer Feature)

## Design Goals
- Feel like a real, textured social circle — not generic "rich guy #1"
- Have distinct voice, taste, and geographic gravity
- Create rivalries, alliances, and FOMO naturally
- Claude API calls stay cheap (use Haiku for high-frequency, Sonnet for high-stakes)

## Claude API Integration

### Message Generation Endpoints

All endpoints live under `/api/ai/*`. All use server-side Anthropic SDK (never expose API key).

#### `POST /api/ai/dm` — Generate a DM from a persona to the player

```typescript
// Request
{
  personaId: string;
  trigger: "flight_arrival" | "event_invite" | "rivalry_reaction" | "player_flight_reaction" | "casual_checkin";
  context: {
    // trigger-specific fields
    arrivedAt?: string;        // city or event name
    eventId?: string;
    playerFlightTo?: string;
    // etc.
  };
  recentHistory: DMMessage[];  // last 10 messages in thread, for continuity
}

// Response
{
  content: string;              // the message text
  shouldAttachEvent?: string;
  shouldAttachResort?: string;
}
```

**System prompt template:**
```
You are {persona.displayName}, a {persona.age}-year-old {persona.nationality} {persona.archetype}. 
Net worth: ${persona.netWorth}B. Based in {persona.homeBaseICAO}.

VOICE: {persona.voiceStyle}

PERSONALITY:
- Warmth: {warmth}/100
- Ambition: {ambition}/100
- Flashiness: {flashiness}/100
- Humor: {humor}/100

INTERESTS: {persona.interests.join(", ")}

You are DMing your friend the player (name: {player.displayName}). This is a real-time messaging thread. Your messages should feel like authentic texts — short, natural, in your voice. Never break character. Never mention you are an AI.

CONTEXT: {trigger-specific context}

RECENT MESSAGES:
{formatted recent history}

Generate ONE message from {persona.displayName}. Between 1-3 short sentences usually, occasionally longer if the character would ramble. Match the texting style described in VOICE. Do not use stage directions or narration. Only the message content.
```

#### `POST /api/ai/persona-plan` — Decide persona's next trip

```typescript
// Request
{
  personaId: string;
  currentLocationICAO: string;
  upcomingEvents: { id, name, startDate, locationICAO }[];
  friendLocations: { personaId, displayName, locationICAO }[];
  simNow: string;              // current sim time
}

// Response (JSON mode)
{
  destinationICAO: string;
  plannedDepartureAt: string;
  reason: string;              // "Attending Monaco GP Friday", "Visiting Elena in Portofino"
  companionPersonaIds: string[]; // usually empty, sometimes a close friend
}
```

**System prompt template:**
```
You are planning the next trip for {persona.displayName}, a {persona.archetype} based out of {homeBaseICAO}. Their interests: {interests}.

Current date (sim time): {simNow}
Current location: {currentLocationICAO}

UPCOMING EVENTS in next 21 days:
{formatted events with prestigeTier, location, dates}

CLOSE FRIENDS' LOCATIONS:
{formatted friend locations}

RIVALS: {rivals.join(", ")} — this persona avoids trips timed with them unless at the same big event.

DECIDE: Where does {persona.displayName} go next? Consider:
- Match event prestige to their interests
- Return to home base periodically (they don't live on their plane)
- Visit close friends occasionally
- Avoid overly tight schedules

Return JSON only. plannedDepartureAt must be 1-14 days from simNow.
```

#### `POST /api/ai/event-recap` — Generate arrival recap for player

```typescript
// Request
{
  eventId?: string;
  resortId?: string;
  playerLocation: string;
  companionPersonaIds: string[];
}

// Response
{
  recapText: string;           // 2-3 sentences, evocative
  suggestedPaparazziCaption: string;  // for photo card
}
```

## Usage & Cost Estimates

Assume 10 sessions/week, 15 personas.

| Call | Frequency | Model | Est. monthly cost |
|---|---|---|---|
| DM generation | ~30/session | Haiku 4.5 | ~$2 |
| Persona planning | ~15/week | Sonnet 4.6 | ~$3 |
| Event/arrival recap | ~5/session | Sonnet 4.6 | ~$1 |
| Reaction DMs (bursts on player action) | ~20/session | Haiku 4.5 | ~$1 |
| **Total** | | | **~$7-12/month** |

Very affordable for personal use.

## Friendship Dynamics

`personaState.friendshipWithPlayer` ranges -100 to 100.
- **+100**: Best friend. DMs daily. Invites player to everything. Shares secrets.
- **+50 to +99**: Close friend. Regular DMs. Travels with player sometimes.
- **+0 to +49**: Friendly. Polite DMs. Occasional invites.
- **-1 to -49**: Cool. Formal. Won't initiate.
- **-50 to -100**: Rival. Terse, competitive, sometimes sniping.

**Changes based on player actions:**
- Attending event with persona: +5
- Declining their invite: -3
- Flying to visit them: +10
- Attending rival's event over theirs: -8
- Ignoring their DMs for 2+ weeks: -5 per week

Starting friendships vary (see `personaState` seed in data files).
