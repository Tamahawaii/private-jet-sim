# JETSTREAM — Yachts System

The second fleet. If jets are how you get there, yachts are where you *live* when you arrive.

## Design Principles

- **Yachts are floating real estate.** You can live on them indefinitely. Helicopter on/off. Host friends aboard.
- **They're slow.** 10-25 knots cruising. A Monaco-to-Ibiza run takes 20+ real hours. Speed up 60x and it's 20 minutes.
- **They dock at marinas, not airports.** New dataset. Coastal cities only.
- **They earn when idle.** Real charter rates are absurd ($400k–$4M/week). This is the primary income engine after Phase 7.
- **They're status.** Your yacht's size, name, and pedigree become part of how friends react to you.
- **Coordinating jets + yachts is part of the game.** Fly to Nice, helicopter to your yacht off Antibes, yacht down to Monaco for the GP weekend.

For the Sasha Volkov archetype. Heritage, elegance, slower but storied.

## Yacht Voyage Math

Same math as flights, adapted for water:

```typescript
// /lib/yacht-sim.ts
export function computeVoyagePath(
  origin: Coordinates,
  destination: Coordinates
): Coordinates[] {
  // Use great-circle like flights, but filter for water
  // For v1: trust the great-circle line. 
  // For v2: integrate a land-avoidance routing library or hand-curate routes past known obstacles (Straits of Gibraltar, Suez, Panama, Cape of Good Hope).
  return greatCircle(origin, destination, { npoints: 48 });
}

export function computeVoyageDuration(
  distanceNM: number,
  cruiseKTS: number
): number {
  return distanceNM / cruiseKTS;  // hours
}

export function computeVoyageCost(yacht: Yacht, hours: number): number {
  const fuelGPH = yacht.lengthM * 18;          // rough estimator
  const fuelCost = hours * fuelGPH * 4.00;     // marine diesel
  const crewCost = hours * yacht.crew * 75;    // crew hourly
  const portFees = 5000 + (yacht.lengthM * 100); // arrival port fees
  return Math.round(fuelCost + crewCost + portFees);
}
```

**Land-avoidance note**: Since yacht routes need to follow coastlines, in v1 we accept that great-circle lines may cut through land on the map (visually slightly wrong, but math-wise the arrival time is still correct). In v2, we add manual waypoint injection for Mediterranean routes (e.g., Gibraltar Strait), Suez, Panama, and Cape Horn. Most recreational yacht play will be intra-Med or Caribbean where this matters less.

## Charter Income (The Economy Piece)

When a yacht has `charterAvailable: true` and `status: "idle"`, the simulation randomly assigns charter bookings when the user opens the app.

```typescript
// /lib/charter-engine.ts
export async function resolveCharters(now: Date): Promise<void> {
  const yachts = await yachtRepo.getAll();
  const idle = yachts.filter(y => y.charterAvailable && y.status === 'idle');
  
  for (const yacht of idle) {
    const lastCheckAt = yacht.lastCharterCheck || yacht.acquiredAt;
    const daysElapsed = differenceInDays(now, new Date(lastCheckAt));
    
    if (daysElapsed < 1) continue;
    
    // For each week of availability, 30-60% chance of booking (higher in summer for Med yachts)
    const weeksElapsed = Math.floor(daysElapsed / 7);
    for (let w = 0; w < weeksElapsed; w++) {
      if (Math.random() < charterProbability(yacht, now)) {
        const booking = await generateCharterBooking(yacht, w, now);
        await charterRepo.create(booking);
        await transactionRepo.create({
          occurredAt: booking.endDate,
          type: 'charter_income',
          amount: booking.revenue,
          description: `Charter: ${yacht.nickname || yacht.modelName} - ${booking.clientName}`,
        });
      }
    }
  }
}
```

Charter revenue is *massive*. A 100m yacht at $2.4M/week, booked 30% of the time, earns **~$37M/year passive**. This is the intended late-game flex — own a giga yacht, charter it when you're not using it, watch $3M/week hit your account.

## How Yachts Interact with Jets

This is where it gets fun. The combined-transport flow:

1. **Plan a trip to Monaco for the GP**
2. **Flight planner** detects you have a yacht near Monaco → offers "Arrive via yacht from [location]"
3. **Book flight**: Honolulu → Nice (your BBJ 787)
4. **Book yacht**: Currently off Portofino → repositioning to Monaco to meet you
5. **Both run simultaneously**: plane flies, yacht cruises, both visible on map in different colors
6. **Arrival**: you land Nice, helicopter over to yacht, sleep aboard, helicopter to Monaco paddock next day

Implementation: in the flight planner, after selecting a destination, we show a "Staying aboard?" option if any of your yachts are within 200nm of destination. Selecting it auto-creates a yacht repositioning voyage.

## The Hosting Mechanic

When your yacht is anchored/berthed at a Tier 4+ marina and friends are within 150nm:

- Host dinner aboard (+3 friendship for each attending friend, -$75k cost)
- Throw party (+5 friendship for attending friends, -$350k cost, prestige bonus if during event week)
- Overnight guests (friend stays aboard, +8 friendship if they accept)

This turns yachts into a *social tool*, not just transport.

## Cost Tuning Note

A full yacht fleet at scale:
- 1 × 140m Lürssen ($650M) + 1 × 100m Lürssen ($280M) + 1 × 40m Benetti ($28M) = $958M invested
- Monthly running cost: ~$4.5M (crew, fuel, berth, maintenance)
- Monthly charter income (if all available): ~$15M on average

Still sustainable vs. $79.7B starting net worth, but now choices matter more. Owning yachts affects budget in a way jets don't — jet hangar fees are trivial, yacht crew for a giga is $2M+/month alone.
