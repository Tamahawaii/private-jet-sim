# RELATIONSHIP UI SPEC (PHASE 8)

## RADAR CHART COMPONENT

Displays relationship metrics as 5-axis radar chart on persona detail page.

### Visual:
```
                AFFECTION
                    100
                     |
                     |
   RIVALRY ---- 50 - + - 50 ---- TRUST
                     |
                     |
                    100
                  HEAT (down)
              ROMANTIC TENSION (down-left)
```

5 axes:
- Top: AFFECTION (warmth)
- Top-right: TRUST
- Bottom-right: HEAT (current activity)
- Bottom-left: ROMANTIC TENSION
- Top-left: RIVALRY

### Implementation:
- Use `recharts` (already in deps): `RadarChart` component
- Tailwind colors: each axis a subtle different hue
- Animated on mount (0 → current value over 800ms)
- Tooltip on hover shows exact metric value
- Legend below: status badge, depth score, last interaction

### Code skeleton:
```tsx
import { Radar, RadarChart, PolarGrid, PolarAngleAxis, PolarRadiusAxis, ResponsiveContainer } from 'recharts';
import type { Relationship } from '@/types';

export function RelationshipRadar({ relationship }: { relationship: Relationship }) {
  const data = [
    { axis: 'AFFECTION', value: relationship.metrics.affection, fullMark: 100 },
    { axis: 'TRUST', value: relationship.metrics.trust, fullMark: 100 },
    { axis: 'HEAT', value: relationship.metrics.heat, fullMark: 100 },
    { axis: 'ROMANTIC', value: relationship.metrics.romanticTension, fullMark: 100 },
    { axis: 'RIVALRY', value: relationship.metrics.rivalry, fullMark: 100 },
  ];
  
  return (
    <div className="w-full h-72">
      <ResponsiveContainer>
        <RadarChart data={data}>
          <PolarGrid stroke="#e5e7eb" />
          <PolarAngleAxis dataKey="axis" tick={{ fontSize: 11, fill: '#6b7280', letterSpacing: '0.05em' }} />
          <PolarRadiusAxis angle={90} domain={[0, 100]} tick={false} axisLine={false} />
          <Radar dataKey="value" stroke="#0b6e8c" fill="#0b6e8c" fillOpacity={0.3} animationDuration={800} />
        </RadarChart>
      </ResponsiveContainer>
    </div>
  );
}
```

## GIFT SENDING FLOW

### Trigger:
- "SEND GIFT" button on persona detail page
- Or: gift action in DM thread

### Modal flow:
**Step 1 — Browse gifts:**
- Filter by category, price range
- Filter "Recommended for [name]" (uses gift.preferredBy)
- Each gift card: image (or category-icon fallback), name, price, brief description
- Click → Step 2

**Step 2 — Personalize:**
- Selected gift summary
- Optional occasion field (autocomplete: "birthday", "after our weekend", "anniversary", custom)
- Optional personal note (textarea, 200 char limit)
- Show projected impact: "+12 affection, +8 heat" (calculated from gift.affinityImpact)
- "SEND" button

**Step 3 — Confirm:**
- "[Gift] sent to [name]. Charged $[amount]."
- Atomic transaction:
  - Burn cash
  - Insert giftsSent record
  - Apply metricsApplied to relationship (compute via affinity engine)
  - Add relationshipEvent of type 'gift-sent' (and 'gift-received' on recipient side)
  - Trigger DM thread reaction (Claude generates short response)

### Reaction DM:
- Generated by Claude using:
  - Persona voice + identity context
  - Gift name + description
  - Their preference (preferredBy match → enthusiastic; mismatch → polite)
  - Personal note context
  - Current relationship status

Example reaction prompts:
- High match (preferredBy includes them, status close-friends): "express genuine pleasure, reference how it shows you know them"
- Low match (gift category doesn't fit them): "appreciative but slightly puzzled — gracefully acknowledge"
- Romantic context (status dating/partners): "warm, intimate tone, suggest meeting up"

## RECEIVING GIFTS FROM PERSONAS

Personas occasionally send gifts to player (Phase 9 will trigger this from behavioral engine; Phase 8 just establishes the schema and UI).

### UI:
- Gift arrives as DM with attached gift card
- Player can react: "Thank them" (auto-DM thank you), "Thank with a gift" (opens gift modal addressed back), "Decline" (rare — would damage relationship)
- Gift logged in giftsSent (fromId = persona, toId = 'player')
- Metrics applied normally
