# JETSTREAM — Billionaire Events Calendar

40+ real-world events the ultra-wealthy actually attend. Each event is seeded into Dexie on first load from `/data/events.json`. Dates reflect typical annual windows — update yearly for accuracy (or script a refresh that shifts dates forward).

## Prestige Tiers

- **Tier 5** — Invite-only, genuinely hard to get into. (Met Gala, Davos, Sun Valley Allen & Co., Bilderberg-adjacent)
- **Tier 4** — Money alone isn't enough, but connections open it. (Cannes Grand Prix, Oscars, Kentucky Derby Millionaires Row)
- **Tier 3** — High spend required, anyone with the money gets in. (Monaco GP paddock, Coachella VIP, Art Basel VIP preview)
- **Tier 2** — Expensive but widely accessible. (Burning Man, Wimbledon Centre Court, Miami F1)
- **Tier 1** — High-end but not exclusive. (Paris Fashion Week public shows, St. Barths NYE)

## Annual Rollover Logic

At the start of each real-world year, run a migration that shifts all event dates forward by 365 days, preserving relative timing. This way the calendar stays fresh indefinitely with zero manual curation.

```typescript
// /lib/seed/rollEventsForward.ts
export async function rollEventsForward(yearsForward: number) {
  const events = await eventRepo.getAll();
  for (const event of events) {
    const newStart = addYears(new Date(event.startDate), yearsForward);
    const newEnd = addYears(new Date(event.endDate), yearsForward);
    await eventRepo.update(event.id, {
      startDate: newStart.toISOString(),
      endDate: newEnd.toISOString(),
    });
  }
}
```

## How Events Drive Gameplay

1. **Calendar view** in `/world` shows next 90 days of events on a timeline + map pins
2. **Event detail** shows attending friends, ticket price, dress code, prestige required
3. **One-tap planning**: "Fly there" from event detail opens flight planner pre-filled
4. **Attendance recorded** when player lands at event ICAO during event window
5. **Prestige gain** on attendance (scaled by tier)
6. **Friend reactions** fire via Claude when you attend a prestigious event
7. **Missed events** generate FOMO DMs from friends who attended ("missed you at Monaco, insane weekend")
